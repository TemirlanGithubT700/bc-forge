## What you can request

**1. API and payment integration**
- Python / TypeScript API integrations and automation.
- Payment webhook and x402 integration review, including replay, idempotency and failure-path test cases.
- Reproducible request/response fixtures, API documentation and CI smoke tests.

**2. Stellar / Soroban developer support**
- Rust smart-contract integration tests and regression cases.
- TypeScript SDK and client-side wallet integration.
- Event indexer, diagnostics and deterministic deployment/rollback preparation.
- Security-focused code review; this is not a substitute for an independent accredited security audit.

**3. Monthly engineering maintenance (recurring)**
- Scheduled dependency/CI checks, external API compatibility checks and incident triage.
- Small approved fixes, clear change logs, and a monthly written health report.
- Optional defined response window and monthly hour cap by agreement.
